Desligar um lado tira de uma vez as regras, os analisadores e os achados de arquivo dele. Serve para um projeto só de Java (sem front) ou só de interface (sem back). Infra e comum (Docker, Kubernetes, segredos, dependências) continua ligado.

Pacotes de regras

Um pacote com regras dos dois lados aparece nos dois, com a contagem de cada lado. A caixa do pacote é uma só: desmarcar “Segurança” tira as regras dos dois lados. Para tirar só um lado, use o escopo acima.

BACK Back-end · 1 pacote · 1 regra
Regras de segurança, qualidade e arquitetura.
FRONT Front-end · 1 pacote · 1 regra
Regras do Angular Style Guide e TypeScript.
COMUM Infra e comum · 1 pacote · 0 regras
Boas práticas de contêiner e manifestos.
